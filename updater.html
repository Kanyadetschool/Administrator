Configure ULI Import
Bulk-fill the UPI field from a NEMIS/KEMIS grade report
How it works: Select the grade, then upload the "Learners Per Grade Per Institution" report. Each row's KCPE/KCSE Index Number is matched against that grade's Assessment No. independently in each selected database, and the matching student's UPI field is set to the row's ULI value. If a row has no matching student in a selected database, a new student record is created there (Name, Assessment No., Grade, and UPI). Records where UPI is already correct are skipped automatically. Always Preview before running the update.
